# AdFilm Web · AIGC 广告制作创意平台

按 Figma 文件「Sandwichlab市场广告营销图」→ 页面「创意工具开发」→ 分区「🌐 Web 端」实现。

```sh
pnpm install
pnpm --filter @adfilm/web dev     # http://localhost:5180
```
